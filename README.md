# Jitter

Jitter is a free macOS menu bar app that keeps your Mac and its display awake, forever or for a set time. An animated coffee bean tells you when it's on duty.

This repository holds Jitter's releases. Download the latest version from **[jitter.adiworks.dev](https://jitter.adiworks.dev)** or from [Releases](https://github.com/akar016012/jitter-releases/releases/latest).

- Requires macOS 15 Sequoia or later.
- Signed with Developer ID and notarized by Apple.
- Updates itself: Jitter checks for new versions every two weeks, or whenever you choose **Check for Updates…** in its menu.
